# V0.57.0-alpha｜Orthogonal 核心家具重作計畫（第一批）

- 任務：`ARCH-0570-ORTHOGONAL-ROOM-PROTOTYPE`（本計畫為輸出物，**本次不執行重作**）
- 後續任務（未核准前不執行）：`ART-0571-CORE-ORTHOGONAL-FURNITURE`（建議 Codex 或明確美術工具）
- 前提：Orthogonal 房間方向經產品負責人[驗收](./V0570_ORTHOGONAL_ROOM_ACCEPTANCE.md)通過後才啟動。
- 相容契約：**保留現有 furniture ID 與存檔相容**；不改 `x/y/r`、footprint、layer、price、unlock。

> 本版正交房間幾何正確，但現有等角 sprite 在平地板上透視不合（Placeholder）。本計畫只鎖定**最核心的 12 件**，不規劃 47 件同步重畫；其餘家具後續分批遷移。

## 原則

- 新素材**必須原創**；**不**直接仿製任何參考遊戲的家具圖案、角色、圖示或介面。
- 正交呈現保留正面／側面與厚度，形成原創 2.5D；不是純頂視。
- anchor 維持「直立物腳底中心、平面裝飾中心」規則（與投影一致）。
- 先做能撐起服務→座位→貓咪三區的最小集合。

## 座標與方向說明

- 目前家具多為 `rotation:"quarter"`（0–3 四向），邏輯 footprint 依 rotation 旋轉。
- 正交房間中「面向」對應：0 面前（下）、1 面右、2 面後（上）、3 面左（實際採用由 `ART-0571` 依 sprite 與 socket 定案）。
- 「方向數」= 本批建議先產出的方向圖數（可先 1–2 向，其餘用 mirror／fallback），非最終全量。
