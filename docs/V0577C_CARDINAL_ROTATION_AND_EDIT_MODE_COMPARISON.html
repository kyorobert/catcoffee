V0577C 比較：正交 90° 旋轉、cardinal 方位與家具編輯

Build 0577b → 0577c（package 維持 0.57.7-alpha）。取代 DEC-027 固定視覺 pivot。所有旋轉消費者共用單一 resolver。

1. 旋轉核心

面向0577b（前）0577c（後）
Sprite 位置來源固定 r0 anchor（base-rotation calibration）實際旋轉 footprint 的 gameplay anchor（resolver）
Sprite vs Occupancy非方形「貼圖在 A、占格在 B」分離永遠同源、同一 resolver 結果
非方形單次 90°貼圖不動（假穩定，掩蓋位移）誠實 corner-pivot 位移（例 counter Δ=−44px/+120px）
4× 旋轉視覺不動但與占格不一致r0==r2、r1==r3，精確歸位、零漂移
邏輯契約兩版皆：(x,y) 左上角不動、奇數旋轉交換寬高、x/y/r 語意與存檔不變

2. 方位語意

面向0577b（前）0577c（後）
方位解析iso 四向 rotationToDirection（down-right…）cardinal {0:south,1:west,2:north,3:east} 順時針
貼圖重用同 4 張 authored PNG；cardinal→key 對照（south→down-right…），不重畫
iso / flat完全未動（rotation/texture/golden/save 對應不變）

3. 家具編輯模式

面向0577b（前）0577c（後）
編輯列#selectionBar 浮在 Canvas 上（第二層）移入 #gameBottomBar，data-mode=edit 就地替換主導覽列
相機浮動列佔相機保留、可能跳動同容器等高切換，viewport 不縮放、相機不跳
觸控目標編輯鈕 ≥44×44 CSS px、safe-area-inset-bottom 保留
退出取消或取消選取 → 還原主導覽列

4. Art Debug

面向0577b（前）0577c（後）
標籤每件 7 行 metadata → 手機重疊字牆artDebug=1 幾何＋單行短標籤；完整資訊只在 artDebugFocus/選取
幾何bounds＋polygon＋anchor 點＋footprint cells、logical pivot（紫圈）、visual pivot（紅點）、resolved x/y/r+方位
